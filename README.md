# Flour — Artisanal Bakery Website

<p align="center">
  <img src="docs/img/logo1_black.png" alt="Flour logo" width="180"/>
</p>

A clean, responsive landing page for an artisanal bakery — handcrafted cakes and pastries, built with plain HTML, CSS, and JavaScript. No frameworks, no build step.

🔗 **Live demo: [tina-shahedi.github.io/Flour](https://tina-shahedi.github.io/Flour/)**

## Features

- Hero section with bakery branding and call to action
- **About** and **Products** sections with photography of cakes and pastries
- **Contact** section
- Fully responsive layout with a mobile menu
- Zero dependencies — one HTML page, one stylesheet, one script

## Repository structure

```text
.
├── index.html      # page markup
├── styles.css      # all styling, hand-written
├── script.js       # mobile menu and page interactions
└── docs/           # logo and product images
```

## Run locally

```bash
git clone https://github.com/tina-shahedi/Flour.git
cd Flour
open index.html      # or: python3 -m http.server 8000
```
